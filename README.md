# 구구독 구구덕

경상북도교육청 구미도서관 캐릭터 **구구독**과 **구구덕**을 환영하는 웹 페이지예요.

책장 사이에 반짝이는 먼지에게 환영의 말을 건네면, 먼지가 모여 구구독이나 구구덕으로 나타나 말풍선으로 대답해요.

## 사용법

- 아래 입력칸에 환영의 말을 적고 "말하기"를 눌러요.
- 처음에는 한 캐릭터가 랜덤으로 나와요. 이름을 부르면 그 캐릭터가, "쌍둥이"·"둘 다"라고 하면 둘이 함께 나와요.
- 한 번 더 말을 걸면 나머지 쌍둥이도 나타나요.
- 계속 말을 걸면 포즈가 바뀌고, 캐릭터를 빠르게 10번 누르면 간지럼을 타요.
- 구구독(파란 모자)을 한 번 톡 누르면 사서 추천 큐레이션 도서 중에서 "오늘의 책"을 뽑아 줘요. 청구기호와 자료실·서가도 알려 줘요. 뽑은 책은 "오늘의 책 카드" 사진(서명·청구기호·서가·날짜 도장·구구독의 한마디)으로 휴대폰에 저장할 수 있어요. 카드는 휴대폰 안에서만 만들어지고 어디로도 보내지 않아요.
- 책장 맨 위 칸의 작은 선반에 책 두 권이 꽂혀 있어요.
  - 「독서 영수증」(남색): 구구덕의 독서 영수증이 열려요. 다 읽은 책 표지를 찍고 제목·별점·기분을 고르면 감열지 영수증처럼 찍힌 이미지(책 사진, 구구덕의 취향 분석, 한마디, 바코드)가 나오고 휴대폰에 저장할 수 있어요. 사진은 휴대폰 안에서만 쓰이고 어디로도 보내지 않아요.
  - 「독서취향테스트」(보라색, 하트 책갈피): 구구덕의 독서 취향 테스트가 열려요.
- 🎮 게임 버튼: 구구독의 책장 정리 대작전, 구구덕의 스무고개 게임, 구구독 구구덕의 책 속 대결(갈림길 이야기 + 미니게임 6가지, 결말 9개).
- 게임과 숨은 비밀에는 효과음이 있어요. 소리는 파일 없이 브라우저에서 만들어요. 오른쪽 위 🔊 버튼으로 끄고 켤 수 있고, 휴대폰 키보드가 열려 있는 동안에는 이 버튼이 잠시 숨어요.

## 파일

내용(대사·문제·책 목록)을 바꿀 때는 **데이터 파일**만 고치면 돼요. 동작을 바꿀 때만 **화면과 동작** 파일을 고쳐요.

### 데이터 파일

| 파일 | 내용 |
|---|---|
| `replies.js` | 알아듣는 말과 대답 목록 (여기서 문장을 더하거나 고칠 수 있어요) |
| `names.js` | 이름 묻기: 묻는 말, 이름 삼행시에 쓰는 글자별 문장, 이름마다 특별한 반응 (이름은 저장하지 않아요) |
| `eggs.js` | 숨은 비밀(이스터 에그) 8가지와 그 대사 (화면에는 힌트가 없어요) |
| `todaybook.js` | 구구독의 오늘의 책: 자료실별 북큐레이션 도서 목록(서명·저자·청구기호·구구독의 한마디). 달마다 이 파일만 바꾸면 돼요 |
| `receipt.js` | 구구덕의 독서 영수증: 다 읽고 난 기분 15가지(2개까지 고름), 취향 유형 6가지, 구구덕 한마디(유형·별점별), 안내 문구 |
| `quiz.js` | 구구덕의 독서 취향 테스트: 질문 15개(할 때마다 10개)와 결과 6가지, 책장에 꽂힌 책 제목 |
| `shelf.js` | 🎮 구구독의 책장 정리 대작전: 분류 칸(KDC 000~900)과 문제로 나오는 책 목록 |
| `riddle.js` | 🎮 구구덕의 스무고개 게임: 난이도, 물어볼 질문 42개, 주인공 20명(전래동화·명작·세계 고전)의 "응" 대답과 그 이유·근거, 결과 |
| `story.js` | 🎮 구구독 구구덕의 책 속 대결: 장면·갈림길·대화, 미니게임 설정(난이도), 결말 9개 |
| `images/chars.js` | 캐릭터 포즈 이미지 (페이지에 넣기 좋게 묶어 둔 파일) |

### 화면과 동작

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대(책장, 입력칸, 게임 창, 끝 인사)와 파일 불러오는 순서 |
| `style.css` | 화면 꾸밈(색·크기·움직임) |
| `app.js` | 페이지의 모든 동작: 캐릭터 나타나기, 말풍선, 말 알아듣기, 이름, 끝 인사, 숨은 비밀, 게임 창과 각 게임, 오늘의 책 카드, 독서 영수증 |
| `story-games.js` | 책 속 대결의 미니게임 6가지(취향 저격 추천, 탑 받치기, 명작 상자, 구름 고리, 무궁화 꽃이 피었습니다, 취향 책 잡기) |
| `story-art.js` | 책 속 대결 미니게임의 그림(올빼미, 용, 상자, 책, 배경 등). 모두 직접 그린 그림이라 외부 이미지를 쓰지 않아요 |
| `sfx.js` | 효과음과 🔊 버튼 |
| `serve.js` | 내 컴퓨터에서 실행할 때 쓰는 작은 서버 (`node serve.js` → http://localhost:5173) |

포즈 이미지는 `images/chars.js` 안에 webp 그림으로 들어 있어요. 포즈를 바꾸거나 더하면 이 파일을 다시 만들어야 해요.
