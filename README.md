# 구구독 구구덕

구미도서관 청소년 공간을 대표하는 캐릭터 **구구독**과 **구구덕**을 환영하는 웹 페이지예요.

책장 사이에 반짝이는 먼지에게 환영의 말을 건네면, 먼지가 모여 구구독이나 구구덕으로 나타나 말풍선으로 대답해요.

## 사용법

- 아래 입력칸에 환영의 말을 적고 "말하기"를 눌러요.
- 처음에는 한 캐릭터가 랜덤으로 나와요. 이름을 부르면 그 캐릭터가, "쌍둥이"·"둘 다"라고 하면 둘이 함께 나와요.
- 한 번 더 말을 걸면 나머지 쌍둥이도 나타나요.
- 계속 말을 걸면 포즈가 바뀌고, 캐릭터를 누르면 간지럼을 타요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 본체 |
| `replies.js` | 알아듣는 말과 대답 목록 (여기서 문장을 더하거나 고칠 수 있어요) |
| `quiz.js` | 🎮 구구덕의 독서 취향 테스트 질문 10개와 결과 5가지 |
| `shelf.js` | 🎮 구구독의 책장 정리 대작전: 분류 칸(KDC 000~900)과 문제로 나오는 책 목록 |
| `names.js` | 이름 묻기: 묻는 말, 이름 삼행시에 쓰는 글자별 문장, 이름마다 특별한 반응 (이름은 저장하지 않아요) |
| `riddle.js` | 🎮 구구독 구구덕의 스무고개 게임: 난이도, 물어볼 질문 22개, 주인공 28명의 "응" 대답과 그 이유, 결과 |
| `images/chars.js` | 캐릭터 포즈 이미지 (페이지에 넣기 좋게 묶어 둔 파일) |
| `originals/` | 캐릭터 포즈 원본 이미지 |
| `serve.js` | 내 컴퓨터에서 실행할 때 쓰는 작은 서버 (`node serve.js` → http://localhost:5173) |

포즈 이미지를 바꾸면 `images/chars.js`도 다시 만들어야 해요.
